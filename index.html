Dairy MLT Builder

Converts a dairy catalogue spreadsheet into a NextLot MLT upload file.
v6.6
Output columns: Lot #, Lot Name, Description, Quantity, Starting bid and Reserve Price.
Vendor / A/C: use the checkbox to hide this line from the NextLot preview and downloaded MLT when required.
Supplementary updates: upload an update sheet after the sale catalogue, compare only the changed nonblank fields, then accept or ignore each proposed update before applying it.
Column mapping: unrecognised populated headings can be mapped to an existing Dairy field or created as a new field and positioned in the MLT. Mappings are saved in this browser for later files. The Current Mapping Excel export lists each MLT heading, where it displays, and every recognised or saved source-column variation underneath that MLT field.
Herdbook links: after the catalogue is loaded, upload a Herdbook link file to add a Pedigree & ABV Link button to matching lots. Exact Herdbook matches are cross-checked against Animal Name. Missing/different names or review statuses are flagged To Check; these can be confirmed individually or all at once before the link is added.
Lot Name uses the source Name column when present. Older files without Name continue to use Tag + animal ID followed by Type. The description includes Vendor, Class, Attribute, Herdbook, DOB, Ltrs/Day, Total Ltrs, Calving Date, Joining, Calved, Due and Mated Sire. Lot Notes appear above the pedigree with a blank row above and below. Only Sire and Dam show initially; any additional Sire or Dam generations are available under the Pedigree button. Tables remain below the pedigree. Breed is currently hidden. A2/A2 and Polled are extracted from Class, while Beta-Casein and Horn values are also shown under Attribute. Calving Date appears in the lot details directly below DOB; a heading of Calved also appears in the lot details. Production Age, Days, Milk, Fat, Fat %, Pro, Pro % and Solids are combined into one production table. Production Age is kept as a numeric year-month code (for example 2-4 or 2-11), even when Excel displays the uploaded value as 2-Apr or 2-Nov. All displayed dates — including DOB/Birth Date, Calving Date, Calved, Joining and Due — are shown as DD/MM/YYYY and are never displayed month-first.
Rows are sorted into Lot # order before preview and export. Blank/non-animal rows are ignored. If a future file has no lot-number column, output lot numbers are created sequentially. Like the Beef MLT Builder, descriptions are automatically padded to a minimum of 8 visible rows. Only the missing blank rows are added at the bottom, and descriptions already at 8 or more rows are left unchanged.
Output file: NextLot MLT.xlsx
Upload Dairy Sale Catalogue File
CSV, XLSX or XLS — reads animal details, breeding details, Last Lact Age (Months), Last Lact Milk, Last Lact Protein, Last Lact Fat, Last Lact Days, SCC, BPI, ASI, HWI, GLPI, OT, MS, Mam, Fert and standard production fields including F&PPI. Ltrs/Day, Total Ltrs, CC/Cell Count, Solids and SC are shown together in a separate table above the production table. The production table keeps Age, Milk, Fat, Fat %, Pro and Pro % together, followed by Days, F&PPI and Solids. Any populated column that is not recognised will be flagged after upload so it can be mapped.

Unrecognised catalogue column mapping

Map an unrecognised heading to an existing Dairy field, ignore it, or create a new MLT field and choose where it should appear. Previously saved mappings can be reviewed, edited or removed below without re-uploading the catalogue. Use Download Current Mapping Excel to export the full mapping register, including all recognised header variations and any mappings you add.

Saved mappings

Review mappings that have been manually saved in this browser. Edit a mapping to reopen it in the controls above, or remove it to return that source heading to automatic/unrecognised handling.
